## Resource Profile: Perfil de Idade gestacional 

| | |
| :--- | :--- |
| *Official URL*:https://hl7.pt/fhir/NoticiaNascimento/StructureDefinition/GestationalAge | *Version*:1.0.0 |
| Active as of 2026-10-20 | *Computable Name*:GestationalAge |

 
Idade gestacional estimada, registada como quantidade em UCUM. Uma idade gestacional em semanas e dias (ex.: 38 semanas e 4 dias) deve ser convertida para dias (270 d). 

**Usos:**

* Refere a este Perfil: [Perfil do recurso Composition que cria as secções da noticia nascimento](StructureDefinition-CompositionNoticia.md)
* Exemplos para este Perfil: [Observation/gestational-age-example](Observation-gestational-age-example.md)

You can also check for [usages in the FHIR IG Statistics](https://packages2.fhir.org/xig/resource/hl7.fhir.pt.obs-neonat|current/StructureDefinition/StructureDefinition-GestationalAge.json)
